# O que aprendemos?

### Nesta aula, aprendemos:

    O conceito de dispositivos computacionais.
    A integração de hardware e software em soluções computacionais.
    As principais divisões de um software: back-end, front-end e banco de dados.
    O papel das equipes de software no desenvolvimento, teste e manutenção de aplicações.
    O conceito de computação pervasiva.
    O conceito de pensamento computacional para resolver problemas de forma lógica.
