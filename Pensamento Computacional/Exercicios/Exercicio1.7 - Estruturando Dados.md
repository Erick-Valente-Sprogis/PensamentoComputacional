# Estruturando dados

A Organo, uma plataforma para criação e gestão de organogramas 
empresariais, está desenvolvendo uma nova funcionalidade que permite 
às pessoas usuárias criar organogramas dinâmicos que se ajustam 
automaticamente a mudanças na estrutura organizacional, como promoções ou 
transferências de funcionários. A equipe de desenvolvimento que você faz 
parte precisa estruturar os dados de forma que essas mudanças sejam 
refletidas instantaneamente no organograma.

Qual abordagem seria mais eficiente para estruturar esses dados?

#### Alternativa B:
Decompor o problema em partes menores, identificar padrões nas mudanças
organizacionais, abstrair informações relevantes e criar um modelo de dados
que permita atualizações rápidas e eficientes, garantindo que o organograma
reflita instantaneamente as mudanças na estrutura organizacional.

#### - Correta, pois essa abordagem utiliza o pensamento computacional  
#### de forma abrangente, decompondo o problema, reconhecendo padrões, 
#### abstraindo informações e criando um modelo de dados eficiente, o que 
#### é essencial para a atualização dinâmica do organograma.
